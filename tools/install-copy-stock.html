📋 Copy Stock

⬆ Drag this button up to the bookmarks bar · អូសប៊ូតុងនេះឡើងទៅរបារ Bookmarks

How to install · របៀបដំឡើង
  1. Bookmarks bar not showing? Press ⌘ Cmd + Shift + B (Windows: Ctrl + Shift + B). · មិនឃើញរបារ Bookmarks? ចុច Cmd+Shift+B
  2. Drag the green 📋 Copy Stock button onto the bookmarks bar. · អូសប៊ូតុងពណ៌បៃតងទៅរបារ
  3. Right-click the old Copy Stock bookmark → Delete, so there is only one. · លុប Copy Stock ចាស់ចោល
  4. Use it exactly as before on the Vrich Sale page. Your name is remembered. · ប្រើដូចមុននៅទំព័រ Sale របស់ Vrich
Can't drag? · អូសមិនបាន?

Copy the code, then right-click the old Copy Stock bookmark → Edit → paste it into URL.
